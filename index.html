How it works

From search to confirmed booking

  1. 1

    Search

    Choose a city and a check-in to check-out range. Houses are listed from KCER 101 up, or newest first.

  2. 2

    Send options

    Tick the houses to offer. The guest gets each one as a single message, then its photos.

  3. 3

    Invoice

    Open Invoices from the chat. The houses you sent are listed first; tap one for dates and price.

  4. 4

    Reserve

    One house, guests, optional note to the host. The PC books it on Airbnb and stops if the price moved.

  5. 5

    Confirm

    The guest is told the reservation was made and that you are waiting for the host's live location.

Questions

Before you install

Android says "App not installed" when I update

Android only updates an app when the new file is signed with the same key as the one installed. If you installed an earlier build, uninstall Karlon first, then install this one. Your chats stay on the server; you only re-enter the server address and your name.

Play Protect warns me about the app

Karlon is installed from this page, not the Play Store, so Google shows a generic warning for apps it doesn't know. Tap More details, then Install anyway.

What server address do I enter?

The address of the KARLCON server, given to you by the KARLCON admin. Without it the app has nothing to show, which is by design: Karlon is for the KARLCON team and partners.

Which Android versions are supported?

Android 7.0 (Nougat) and newer.

Does Reserve book the house straight away?

Reserve sends a request to book on Airbnb from the KARLCON PC, with the price checked first. The host still has to accept. If anything looks wrong before the request is sent, nothing is booked and you can try again.
